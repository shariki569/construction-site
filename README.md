# construction-site

Apex Build Philippines — a 5-page Next.js website for a PCAB-licensed general contractor in Cebu.

## Local

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- `/` Home
- `/about` About Us
- `/services` Services
- `/projects` Projects
- `/contact` Contact

## Deploy

This repo deploys as a static Next.js export.

- **Vercel:** import `shariki569/construction-site` (or `npx vercel --prod`)
- **GitHub Pages:** enabled via GitHub Actions on `main` at `https://shariki569.github.io/construction-site/`
